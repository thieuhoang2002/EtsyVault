# Contributing to EtsyVault

Thank you for your interest in contributing to **EtsyVault**! We welcome bug reports, feature suggestions, documentation improvements, and pull requests.

## Code of Conduct

Please be respectful, constructive, and considerate when interacting in discussions, issues, and pull requests.

## How to Contribute

### Reporting Bugs
- Check the existing [Issues](https://github.com/thieuhoang2002/EtsyVault/issues) to ensure the bug hasn't already been reported.
- Open a new issue using our **Bug Report** template, including steps to reproduce, OS details, and logs/screenshots.

### Suggesting Enhancements
- Open a **Feature Request** issue to discuss new capabilities, UI improvements, or additional export formats.

### Submitting Pull Requests
1. Fork the repository and create your feature branch from `main`:
   ```bash
   git checkout -b feature/my-new-feature
   ```
2. Build and verify the solution with .NET 10 SDK:
   ```bash
   dotnet build
   dotnet test
   ```
3. Commit your changes following standard Conventional Commits:
   ```bash
   git commit -m "feat: add support for new export format"
   ```
4. Push to your branch and submit a Pull Request against `main`.

## Development Stack
- **.NET 10 SDK**
- **AvaloniaUI 12 + FluentAvalonia**
- **CommunityToolkit.Mvvm**

Thank you for helping make EtsyVault better for sellers worldwide! 🛡️
